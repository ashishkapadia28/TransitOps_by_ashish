# TransitOps

TransitOps is a comprehensive Fleet Management System built with Django. It provides a centralized platform to manage vehicles, drivers, trips, maintenance, and financials for your fleet operations.

## Features

*   **Vehicle Management:** Track vehicle details, status (available, on trip, in shop, retired), types, odometer readings, and acquisition costs.
*   **Driver Management:** Manage driver profiles, licenses, and assigned vehicles.
*   **Trip Tracking:** Plan and monitor trips, including origin, destination, assigned vehicle/driver, cargo weight, and planned distance.
*   **Fuel & Expense Logging:** Keep track of fuel consumption, tolls, and other expenses associated with each vehicle.
*   **Revenue Tracking:** Log revenue generated by specific vehicles.
*   **Maintenance Logs:** Record maintenance activities, costs, and automatically update vehicle status to 'in shop' when maintenance is required.
*   **User Authentication & Dashboard:** Secure login system with role-based access and an analytics dashboard (built using Django templates).

## Technology Stack

*   **Backend:** Python, Django
*   **Database:** SQLite (default for development, can be configured for PostgreSQL/MySQL)
*   **Frontend:** Django Templates (HTML/CSS/JS)

## Setup and Installation

Follow these steps to run the project locally:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/ashishkapadia28/TransitOps_by_ashish.git
    cd TransitOps_by_ashish
    ```

2.  **Create a virtual environment:**
    ```bash
    python -m venv venv
    ```

3.  **Activate the virtual environment:**
    *   On Windows:
        ```bash
        venv\Scripts\activate
        ```
    *   On macOS/Linux:
        ```bash
        source venv/bin/activate
        ```

4.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

5.  **Set up environment variables:**
    *   Copy the `.env.example` file to a new file named `.env`.
    *   Update the variables in `.env` as needed.

6.  **Apply database migrations:**
    ```bash
    python manage.py migrate
    ```

7.  **Create a superuser (for admin access):**
    ```bash
    python manage.py createsuperuser
    ```

8.  **Run the development server:**
    ```bash
    python manage.py runserver
    ```

9.  **Access the application:**
    *   Main App: `http://127.0.0.1:8000/`
    *   Admin Panel: `http://127.0.0.1:8000/admin/`

## Project Structure

*   `backend/`: Core Django settings and configurations.
*   `fleet/`: App containing models and logic for vehicles, drivers, trips, fuel, expenses, and maintenance.
*   `users/`: App handling user authentication, forms, custom user models, and frontend templates.
*   `staticfiles/`: Directory for static assets (CSS, JS, images).
*   `deploy/`: Configuration files for deployment (e.g., nginx).
